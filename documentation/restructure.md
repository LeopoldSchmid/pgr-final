# Navigation Restructure (Historical)

Status: historical reference only

This file previously contained an intermediate restructuring plan for moving the app from phase-based navigation toward feature-based navigation with persistent trip context.

It is no longer a source of truth.

Use these documents instead:
- `documentation/stabilization_plan.md`
- `documentation/status_quo.md`
- `documentation/testing.md`

Historical intent of the old document:
1. introduce persistent trip context
2. move toward feature-oriented navigation
3. add stronger controller/system test coverage around navigation and context switching

Current note:
- Large parts of that restructuring have been implemented in code.
- Remaining work should be planned from the current codebase and the stabilization plan, not from the original redesign notes.

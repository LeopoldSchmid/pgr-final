Interactivity & Hierarchy Guidelines

The Gutenberg Lead: Interactive selectors (checkboxes, radio buttons) must lead the content (left-aligned). This establishes a clear "scan-and-act" anchor for the user, separating data manipulation from data consumption.

Contextual Transformation (The CAB Pattern): To maximize vertical real estate and reduce cognitive load, primary toolbars (like "Add Item") should mutate into Contextual Action Bars (CAB) when an item is selected.

Rule: If a global action and a selection action are mutually exclusive in the current user workflow, they must occupy the same physical space to maintain focus.

The Cluster Guard: Avoid stacking multiple distinct primary action triggers (e.g., FABs + Add Buttons) in a single quadrant. Use contextual menus to resolve interaction conflicts.
